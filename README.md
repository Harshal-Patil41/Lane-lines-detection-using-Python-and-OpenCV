# Lane Lines Detection Using Python and OpenCV

## Overview
This project detects road lane lines using Computer Vision techniques with Python and OpenCV. The system processes road images and video streams to identify lane boundaries in real time, simulating the basic functionality used in autonomous driving and Advanced Driver Assistance Systems (ADAS).

The project uses image processing techniques such as grayscale conversion, Gaussian blur, Canny Edge Detection, Region of Interest masking, and Hough Transform to detect lane lines accurately on highways.

---

## Features
- Real-time lane line detection
- Road image and video processing
- Canny Edge Detection
- Region of Interest (ROI) masking
- Hough Line Transform
- Lane visualization on road images
- OpenCV-based image processing pipeline

---

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib
- Jupyter Notebook

---

## Project Workflow
1. Load image or video frame
2. Convert image to grayscale
3. Apply Gaussian Blur for noise reduction
4. Perform Canny Edge Detection
5. Apply Region of Interest masking
6. Detect lane lines using Hough Transform
7. Draw detected lanes on original image
